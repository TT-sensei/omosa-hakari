# おもさを はかろう

重さの目盛を読み、はかりの針が示す重さを考える、タブレット向けの算数教材です。

## 公開ページ

https://tt-sensei.github.io/omosa-hakari/

## 学習内容

はかりの目盛を見て、針が示している重さを読み取ります。

- はかりの目盛を読む
- 目盛の間の位置から重さを考える
- kg・gなどの重さの単位を意識する
- 自分で答えを入力して確かめる

画面上のはかりを見ながら、重さの量感と目盛を読む力を練習できます。

## 特徴

- タブレットで操作しやすいシンプルなUI
- はかりを大きく表示し、問題を主役にした設計
- 重さを入力してその場で正誤を確認
- 繰り返し練習できる
- GitHub Pagesで動作する静的HTML/CSS/JavaScript
- 外部API・APIキー・バックエンドなし

## 開発方針

算数の学習を主役にし、キャラクターや演出は補助として扱っています。
学校や家庭で、重さの学習の練習用として利用できます。
